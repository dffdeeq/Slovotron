# 🧠 Словотрон 9000 — CLI

Терминальная версия [Словотрона](../readme.md): полноэкранный TUI прямо в консоли.
Подключается к чату Twitch, проверяет слова через `api.contextno.com` и в реальном
времени рисует ленту угадываний, лучшие совпадения, лидерборд, статистику раунда,
подсказки и экран победы.

## Требования
- **Node.js 18+** (нужен встроенный `fetch`).
- Современный терминал: **Windows Terminal / PowerShell 7** на Windows, любой
  Unix-терминал (bash/zsh), iTerm2, и т.п.

## Установка
```bash
cd cli
npm install
```

## Запуск

**PowerShell (Windows):**
```powershell
node slovotron.mjs --channel fra3a
```

**Unix (bash/zsh):**
```bash
node slovotron.mjs --channel fra3a
```

Без `--channel` (и без сохранённого канала) сразу откроется экран настроек —
введите имя канала и нажмите `S`.

## Опции
| Опция | Описание |
|---|---|
| `--channel <имя>` | канал Twitch |
| `--restart <сек>` | пауза перед новым раундом после победы (по умолч. 20) |
| `--no-sound` | выключить звуковой сигнал терминала |
| `--ascii` | ASCII-режим (без эмодзи и юникод-рамок) для старых терминалов |
| `--reset-leaderboard` | очистить таблицу победителей |
| `--help`, `-h` | справка |

## Управление
| Клавиша | Действие |
|---|---|
| `q` | выход |
| `s` | настройки |
| `l` | лидерборд (полный) |
| `i` | как играть |
| `t` | форсировать подсказку |
| `r` | рестарт раунда |

В чате работает команда `!подсказка` — голосование за подсказку (нужно ≥50%
участников раунда, кулдаун 1 минута), как в веб-версии.

## Где хранятся данные
Настройки и лидерборд лежат в JSON:
- **Windows:** `%APPDATA%\slovotron\`
- **Unix/macOS:** `$XDG_CONFIG_HOME/slovotron/` или `~/.config/slovotron/`

## Зависимости
Минимальные, все pure-JS, без нативной сборки: `tmi.js` (чат Twitch),
`string-width`, `wrap-ansi`, `log-update`, `picocolors` (отрисовка TUI).
HTTP — через встроенный `fetch`.
